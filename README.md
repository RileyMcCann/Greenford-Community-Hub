# 🌿 Greenford Community Hub

**A community-focused website developed using HTML5 and inline CSS as part of my web development studies.**

## 📖 About the Project

Greenford Community Hub is a fictional community centre website designed to provide residents with information about local activities, sporting opportunities and community services.

The project was created to develop my understanding of HTML, website structure, navigation and basic web design principles.

As I continue learning web development, I plan to introduce additional features and improve the website's accessibility, functionality and overall user experience.

## ✨ Current Features

### 🏠 Home Page
- Navigation bar linking all three pages.
- Custom Greenford Community Hub logo and background.
- Introduction to the community centre.
- About Us section explaining its purpose.
- Rounded, semi-transparent content containers.

### ⚽ Activities Page
- Seven sports activities: Football, Basketball, Badminton, Cricket, Athletics, Volleyball and Tennis.
- Individual activity descriptions and images.
- Session schedules, age groups and pricing.
- Side-by-side image and text layouts using Flexbox.

### 📞 Contact Us Page
- Community centre contact information.
- Fictional address, telephone number and email.
- Opening hours.
- Information about visiting the centre.

## 🛠️ Technologies Used

**HTML5**
- Page structure and semantic elements.
- Hyperlinks and navigation.
- Images and alternative text.
- Headings, paragraphs and text formatting.

**Inline CSS**
- Colours, fonts and backgrounds.
- Rounded corners and transparent containers.
- Flexbox layouts.
- Spacing, alignment and image sizing.

**Git and GitHub**
- Version control.
- Commit history and project updates.
- Issue tracking for bugs and planned features.

No JavaScript frameworks or external CSS libraries are currently used.

## 🚀 Running the Project

This project is intended primarily as a demonstration of my HTML development skills rather than a publicly hosted website.

To view it locally:

1. Download or clone this repository.
2. Extract the files if downloaded as a ZIP.
3. Keep the HTML files and images in their original folder structure.
4. Open `index.html` in a web browser.
5. Use the navigation bar to explore the other pages.

No additional software or dependencies are required to view the website.
